## The one step iOS won't let the app do

iOS registers the location the moment Pro is active, but it stays **off until you switch it on** — Apple's rule, so no app can add itself to your Files sidebar without you. The app can only point you there.

1. Open the **Files** app.
2. Tap **Browse** (bottom right on iPhone; the sidebar on iPad).
3. Tap the **⋯** button (top right) → **Edit** — or on iPad, scroll the sidebar to *Locations* and tap Edit.
4. Turn on **NFS Files**.
5. Tap **Done**. Your servers appear under Locations → NFS Files.

The card in NFS Files turns from amber *Finish setup* to normal once this is done — it re-checks every time you return to the app.

## What you can do there

- Open any file from any app's file picker — Pages, Procreate, a video player, Mail attachments — straight from the NAS.
- Save from any app back to the NAS.
- Drag between folders, rename, delete, create folders. Moves between folders on the same server are done server-side (no re-upload).
- Files.app downloads on demand; nothing is synced in bulk.

## If the location lists nothing

- **Not turned on yet** — see above. This is nearly always it.
- **NFS Files was renamed a server** — renaming re-registers the location and resets the switch. Turn it on again.
- **The server isn't reachable** from where you are (different network, VPN). The location is live; it just can't list. Check the dot on the server card.
- **Pro isn't active on this device** — Settings → NFS Files Pro → *Restore Purchase* if you bought on another device with the same Apple ID.

## Removing it

Turn Pro off? You can't — it's a one-time purchase — but the location goes away if you delete every server, and it disappears entirely if you delete the app.
