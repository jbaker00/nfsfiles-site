## What it does

<div class="features">

<div class="feature" markdown="1">

<span class="ic"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round"><circle cx="11" cy="11" r="7"/><path d="M21 21l-4.3-4.3"/></svg></span>

### Finds your NAS

Bonjour discovery, a MOUNT export list ("Find Shared Folders") and a full network scan for servers that advertise nothing.

</div>
<div class="feature" markdown="1">

<span class="ic"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M7 16V4M7 4L3 8M7 4l4 4M17 8v12m0 0l4-4m-4 4l-4-4"/></svg></span>

### Speaks v3 and v4

Tries NFSv4 first, falls back to NFSv3 automatically — or pin a version per server.

</div>
<div class="feature" markdown="1">

<span class="ic"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M22 19a2 2 0 0 1-2 2H4a2 2 0 0 1-2-2V5a2 2 0 0 1 2-2h5l2 3h9a2 2 0 0 1 2 2z"/></svg></span>

### Browse fast

Folders first; sort by name, date or size; instant search; live free-space readout.

</div>
<div class="feature" markdown="1">

<span class="ic"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><polygon points="6 3 20 12 6 21 6 3"/></svg></span>

### Preview everything

Photos, video, PDFs and documents open right in the app, with the system share sheet one tap away.

</div>
<div class="feature" markdown="1">

<span class="ic"><svg width="22" height="22" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M17 1l4 4-4 4"/><path d="M3 11V9a4 4 0 0 1 4-4h14M7 23l-4-4 4-4"/><path d="M21 13v2a4 4 0 0 1-4 4H3"/></svg></span>

### Transfer both ways

Download with progress; upload files and photos; rename, delete, create folders, move between folders.

</div>
